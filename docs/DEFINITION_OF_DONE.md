# Definition of Done

## Task

A task is done when:

- requested behavior exists;
- important failures are handled;
- invariants remain true;
- relevant tests pass;
- documentation matches code;
- no secret or real financial data was added;
- no planned feature is described as shipped;
- limitations are reported.

## Stage

A stage is done when:

- stage acceptance criteria pass;
- required tests/checks are green;
- the diff was reviewed;
- current task and decisions are updated;
- the next stage is bounded.

## Portfolio release

Release-ready means:

- clone-to-demo instructions work;
- no paid credential is required by default;
- Compose smoke covers upload → processing → correction → approval → export;
- all fixtures are fictional;
- durable jobs survive process restarts;
- security, database, and code reviews have no unresolved high-severity findings;
- README contains real screenshots and honest limitations;
- no manual database edits are needed for the demo.
